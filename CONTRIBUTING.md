# Contributing to ROSE App

Thank you for contributing to the ROSE App project.  
Please follow the guidelines below to keep the project organised and consistent.

---

## Branching

Create a new branch for each feature:
Push your branch:

---

## 📌 Commit Messages

Use clear, descriptive commit messages:

- `Add event creation API`
- `Fix booking validation`
- `Improve attendance model`
- `Update README`

---

## 📌 Pull Requests

Before opening a pull request:

1. Make sure your branch is up to date with `main`
2. Test your changes locally
3. Add comments if your code needs explanation

---

## 📌 Coding Style

### Backend (PHP)
- Use clear variable names
- Keep controllers small and focused
- Use models for database logic

### Frontend (React)
- Use functional components
- Keep components small and reusable
- Store API URLs in `.env`

---

## 📌 Environment Setup

### Backend
Copy `.env.example` to `.env` and update values.

### Frontend
Copy `.env.example` to `.env` and update the API URL.
